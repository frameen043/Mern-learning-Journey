                 MERN Stack Overview

 MongoDB

 Answer:
MongoDB is a document-based, open-source database designed for high-performance and automatic scaling. It is a NoSQL database, meaning it stores data in flexible, rather than traditional table rows and columns. It stores data such as user accounts, product catalogs, and application logs efficiently. MongoDB Atlas is the fully managed cloud database service offered by MongoDB, whereas MongoDB Compass is a graphical user interface (GUI) tool used to visually explore, query, and manage local or remote databases.

Express.js

Answer:
Express.js is a minimal and flexible web application framework for Node.js. It is strictly used on the backend side of web development to handle server operations and server routing. Express.js helps in creating robust RESTful APIs by providing a simple routing mechanism to handle HTTP requests like GET, POST, PUT, and DELETE. An example of an Express.js route is: `app.get('/api/users', (req, res) => res.json(users));`, which listens for requests on the `/api/users` endpoint and returns a list of users.

React

Answer:
React is an open-source JavaScript library created by Meta for building user interfaces, especially single-page applications. It is strictly used on the frontend side to design interactive and dynamic user interfaces. A component in React is an independent, reusable piece of UI code (like a button, navbar, or form) that manages its own state and markup. Reusable components are extremely useful because they eliminate repetitive code, keep the codebase organized, and make long-term maintenance much easier.

 Node.js

Answer:
Node.js is an open-source, cross-platform JavaScript runtime environment that allows developers to execute JavaScript code outside of the web browser, directly on the server. Node.js uses npm (Node Package Manager) to manage external packages, libraries, and project dependencies. In a MERN application, Node.js serves as the backbone of the backend server, hosting Express.js server routes and managing communication between the React frontend UI and the MongoDB database.
