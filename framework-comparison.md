 Questions & Answers

 1. Why is MERN called a full-stack JavaScript stack?
MERN is called a full-stack JavaScript stack because every component of the application—React on the frontend, Node.js and Express on the backend, and MongoDB (which uses JSON/BSON syntax)—uses JavaScript. Developers can build the complete application using a single language.

 2. What is one major difference between Node.js, Laravel, and Django?
The primary difference lies in their underlying programming languages and design philosophy: Node.js uses asynchronous JavaScript for high-concurrency event-driven performance, Laravel uses PHP with an MVC architecture focused on web development, and Django uses Python prioritizing rapid development and "batteries-included" built-in features.

 3. Which framework would you personally like to explore after MERN?
I would like to explore "Django" after MERN because it uses Python, which is widely used in Artificial Intelligence, Machine Learning, and Data Science, making it ideal for building data-driven backend applications.

4. Why will MERN be the primary stack used in this course?
MERN is the primary stack because learning a single language (JavaScript) allows students to build both full-stack frontend and backend applications efficiently without switching programming paradigms.
